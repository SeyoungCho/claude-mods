# claude-mods

Small [mods](https://code.claude.com/docs/en/plugins) for Claude Code. This repository is a plugin marketplace (`syc-claude-mods`), so you can install any mod in it by name.

| Mod | What it does |
| --- | --- |
| [`session-cost`](./session-cost) | Shows this session's token usage and USD cost in a band above the prompt |

## Install

At the prompt of a terminal session:

```
/plugin install <mod> --marketplace SeyoungCho/claude-mods
```

In the desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `SeyoungCho/claude-mods`, then **Add plugin**.

Mods need Claude Code v2.1.287 or later (desktop app v2.1.286 or later).
